# PING봇 직업 가이드 카드

마비노기 모바일 길드 카톡봇(PING봇)의 `!직업명가이드` 명령에서 쓰는 직업별 세팅 카드 이미지입니다.

## 카드 고치는 법 (자동 반영)
1. 루트의 직업 카드 PNG(예: `10_ice.png`)를 같은 이름으로 덮어써서 push
2. 카드 요약이 바뀌었으면 `db/classsum.txt`의 그 직업 줄도 고쳐서 같이 push
   (탭으로 구분: 파일명, 직업, 계열, 장신구, 무기, 엠블럼, 개조, 세공, 시즌 스탯, 스탯 추천, 핵심 한 줄, 딜사이클)
3. GitHub Actions(`카드 자동 갱신`)가 미리보기 요약 이미지(`og/`)를 다시 만들고 `db/cardver.txt` 버전을 올림
4. 봇은 10분 안에 새 버전 링크, 1시간 안에 새 요약 텍스트를 씀
